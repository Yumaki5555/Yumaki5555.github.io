# 日本を知る。（入口サイト）

公開先：https://yumaki5555.github.io/ （リポジトリ：Yumaki5555/Yumaki5555.github.io）

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `index.html` | ページの骨組み（入口の2つのタブ「地域から調べる」「テーマから探す」・このサイトについて・掲載情報について） |
| `sites.js` | **掲載サイトの一覧**（テーマから探すの12枚のカード）。サイトを足す・直すときはここだけ書きかえる |
| `site-cards.js` | 「テーマから探す」のカードのHTMLを作る（`main.js` と `_tools/build_cards.mjs` が使う） |
| `main.js` | **ページの状態と URL をまとめて扱う**（`window.PortalState`。URL を読む・書きかえる・戻る／進むはここだけ）、入口の2つのタブの切りかえ、テーマのカードを sites.js から作り直す（テーマを初めて開いたとき）、スマホのメニュー、上へ戻るボタン、ページの更新日の読み取り |
| `region.js` | 「地域から調べる」の地図（地方ごとの拡大）・名前で探す・一覧から選ぶ・選ぶ画面と情報の画面の切りかえ。地域が変わったら `PortalState.set` で URL を頼み、`PortalState.on` で戻る／進むを受け取る（自分では URL を読まない） |
| `region-topics.js` | **地域を選んだときのカード**（地域の8分野＋全国共通の2サイト）。各専門サイトへの地域の引き継ぎ方と、代表的な数値の読み取り方 |

| `data/municipalities.json` | 市区町村の一覧（`_tools/build_municipalities.py` で作る。手で直さない） |
| `img/shots/` | カードに出す各サイトの実際の画面（800×450・16:9 の WebP） |
| `favicon.svg` | ブラウザのタブに出る小さな絵 |
| `ogp.png` | SNSで共有したときに出るサムネイル（1200×630） |
| `_ogp/ogp.html` | サムネイルの元。直したら Edge で撮り直す（`_` で始まるフォルダは公開されません） |
| `_tools/` | 地図・市区町村一覧を作り直す道具と、テーマのカードを index.html に書きこむ道具（公開されません） |

## 入口の2つのタブ

- タイトルの下に「どちらから調べますか？」と、同じ大きさの「地域から調べる」「テーマから探す」を並べています。押した方の中身だけを下に表示します（最初はどちらも開きません）。
- 「地域から調べる」「テーマから探す」の2つだけがタブ（`role="tab"`）です。地図の都道府県・地方ごとの拡大（`aria-pressed`）・地域の選択例・地域を変える・URLをコピーなどは、ふつうのボタンです。専門サイトやページ内の場所へは、ふつうのリンクで移ります。
- 中身は開いたときに初めて作ります（地図は「地域から調べる」、テーマのカードの作り直しとページの更新日の読み取りは「テーマから探す」を初めて開いたとき）。閉じている側の画像やデータは読みません。

### URL とページの状態（main.js の `PortalState`）

状態は3つに分けて持ちます：**表示モード**（入口のボタンだけ／地域から調べる／テーマから探す）、**選んでいる地域**（全国・都道府県・市区町村）、**ページ内の移動先**（`#top`・`#area`・`#themes`・`#research`・`#learn`・`#participate`・`#about`・`#policy`）。

表示モードは、URL から次の順番で決めます。

1. 表示モードを表すハッシュ：`#area`＝地域、`#themes`・`#research`・`#learn`・`#participate`＝テーマ
2. `?view=area` / `?view=themes`
3. 正しい `?area=コード` があれば地域
4. どれもなければ、入口の2つのボタンだけ

`#top`・`#about`・`#policy` は移動先だけを表し、表示モードは変えません（テーマを見ているときにロゴを押すと `?view=themes&area=07#top` のようになり、読み込み直してもテーマのまま）。

| URL | 表示 |
|---|---|
| `/`、`/#top` | 入口の2つのボタンだけ |
| `/#area` | 地域から調べる（地域を選ぶ前） |
| `/#themes`、`/#research` など | テーマから探す（その分類の場所へ移動） |
| `/?area=07`、`/?area=07#top`、`/?view=area&area=07` | 福島県の情報 |
| `/?area=07#themes`、`/?view=themes&area=07` | テーマから探す（福島県の選択は残る） |

- タブを押すと表示モードだけが変わり、地域は残ります。地域を選ぶと地域だけが変わり、タブは変わりません。どちらも履歴に足します（`pushState`）。
- 開いたときの URL は、同じ状態を表す短い形に整えます（`replaceState`。例：`?view=area&area=07` → `?area=07`、`?view=themes&area=07` → `?area=07#themes`）。表示モードと合わないハッシュは残しません。
- 不正な地域コード（`?area=99`・`?area=abc` など）は無視して URL から消します。市区町村の一覧にない6けたのコードは、その都道府県に直します。
- 戻る・進むでは、表示モードと地域を URL のとおりに戻します（スクロールの位置はブラウザが戻します）。
- JavaScript が動かないとき（4秒たっても main.js が動かないときも）は、タブを出さずに両方の中身を表示します（`index.html` の先頭の小さなスクリプトと `style.css` の `.js`）。

## 地域から調べる

- 地域を選ぶ前は「選ぶ画面」（地図・名前で探す・一覧から選ぶ・地域の選択例）を出し、選んだら閉じて「情報の画面」（地域の名前と、地域の8分野＋全国共通2サイトのカード）を出します。「地域を変える」でまた開きます。地域つきのURLで開いたときは、最初から情報の画面です。
- 市区町村は、情報の画面の「市区町村で絞り込む」でも選べます。「〇〇県全体に戻る」で都道府県に戻れます。
- 地域は URL の `?area=` で表します。都道府県は2けた（例 `?area=13`）、市区町村は全国地方公共団体コードの6けた（例 `?area=131083` 江東区）。このURLを共有すると、同じ地域を選んだ状態で開きます。
- 政令指定都市は市全体で1つ（区は選べません）。北方領土の6村は、どの専門サイトにもページがないので入れていません。
- 市区町村の一覧（約78KB）と、各専門サイトのデータは、地域を選ぶまで読みません。一度読んだデータは、地域を変えても読み直しません。
- 数値は、各専門サイトが公開しているデータを、地域を選んだときにその場で読み取ります（入口サイトに数値を書き写していないので、各サイトが更新されれば自動で新しくなります）。
- 「0件」と、それ以外を必ず分けます：確認済みで0件／データ未掲載／調査対象外／未確認／取得失敗。読み込みに15秒以上かかったときも「取得失敗」です（0件とは書かない）。
- 各カードには、どのページが開くかを短い言葉で書きます：✓ 地域を引き継ぎ／！ 都道府県まで（市区町村のページがない）／－ 引き継ぎなし（サイトのトップ）／○ 全国（地域を選ぶ前）／全国共通（下の2サイト）。
- 8分野の下に「D 全国共通の情報も調べる」として、政策ログJP（国の政策・法案）と世界の感染症と日本の水際対策を、同じ形のカードで出します。国全体・世界の情報なので、地域は引き継がず（トップページが開く）、地域ごとの数値も出しません。「テーマから探す」の12サイトのカードはそのまま残しています。
- リンクは、データを読む前に決められる確実な形を先に出し、データを読んで市区町村のページがあると分かったら差しかえます（民泊・MOUの市区町村・パブコメの市区町村）。データが読めなくても、カードとリンクは残ります。
- カードは「分野名 → この地域で分かること → 数値 → 時点・範囲 → 開くページ → 詳しく調べるボタン」の6段で、同じ行のカードの段の高さをそろえています。

### 地図・市区町村一覧を作り直すとき

```
python _tools/build_map.py <mou-map の data/geo/japan_prefectures.topojson>
python _tools/build_municipalities.py <総務省の全国地方公共団体コードの xlsx> "令和6年1月1日更新"
```

市区町村の合併などで総務省のコード表が更新されたら、2つめを実行し、`region.js` の `municipalities.json?v=` と、`index.html` の「掲載情報について」の更新日も直します。

## サイトを追加・修正するとき

`sites.js` を直したら、入口サイトのフォルダで次を実行し、`index.html` にカードを書きこみます（JavaScript が動かないときもカードが出るように）。

```
node _tools/build_cards.mjs
```

### サイトを追加するとき

`sites.js` の `window.SITES` に1件足します。並べた順番が、そのままカードの順番になります。
分類ごとの件数と全体のサイト数は、この一覧から自動で数えて表示します。

```js
{
  id: "new-site",               // 半角英数字の名前（ほかと重ならないもの）
  category: "research",         // research（調べる）/ learn（学ぶ）/ participate（参加する）
  name: "サイト名",
  url: "https://～",
  q: "興味を引く短い問いかけ？",
  desc: "何を検索・比較・確認できるかを1〜2文で。変わる件数は書かない",
  shot: "img/shots/new-site.webp",  // 実際の画面を 16:9 で撮り、800×450 の WebP にする
  alt: "画面の説明（読み上げ用）",
  highlight: "見どころをひとこと",   // なくてもよい
  // ほかの方のサイトなら、運営者を明記する（カードに「運営：〇〇さん／X：@〇〇」と出ます）
  operator: { name: "〇〇さん", x: "https://x.com/〇〇" }
}
```

画面の写真は、架空の画面や AI で作った画像は使わず、必ず実際のサイトを撮ります。
撮り直したら、`index.html` の「掲載情報について」にある撮影日も直します。

css・js・`data/` を直したら、`index.html` の `?v=日付` も書きかえる（見る人のブラウザに古いファイルが残らないように）。

## ページ更新日について

`checkUpdate: true` のサイトだけ、サイトから返ってくる最終更新日時を読み取って表示します。
読み取れるのは yumaki5555.github.io のサイトだけです。読み取れなかったときは何も表示しません。
